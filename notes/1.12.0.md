Kind: feature

- **Its folder says whose it is.** Learning now tells Kehikot that the learning folder in a project is its own and holds the questions written about each epic's paper and how they were answered, so a module that shows the project's files can say what a file there is and who writes it.

## For agents

- Learning now provides the `module.folders` service: `{ name: 'Learning', folders: [{ folder: 'learning', says: …, derived: false }] }`. Read it with `services.find('module.folders')` and `foldersOwned`.
- Learning does not provide `cue.targets`: none of its tools shows anything on its page (`quizzes` and `quiz_state` read, the others write), so a walk-through has nothing here to cue.
